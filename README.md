# Futuristic Blog Web App

A modern, scalable blog platform with a futuristic green-white theme, built using Vanilla JS, Tailwind CSS, Flask, and Docker.

## Features
- Dynamic blog interface with sidebar (podcast episodes, filtering), main content (markdown-rendered posts), and navigation.
- Secure Flask backend with JWT-based authentication for read/edit access.
- Admin panel for managing posts and media.
- Dockerized for development and production with Nginx reverse proxy.

## Setup

### Prerequisites
- Docker & Docker Compose
- Node.js (for Tailwind CSS compilation, optional)
